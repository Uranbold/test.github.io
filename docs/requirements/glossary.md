No agent and no code composes a spoken number outside that table, and a value with no entry is a defect. **Attributive numerals.** A number before a unit noun («метр», «метрт», «километр», «километрт») is read in the attributive form. The Mongolian rounding and the spoken-form layer are implemented on Android with NAV-016, in one coordinated change with the NAV-017 web port and the regenerated golden set, after NAV-005 is accepted and NAV-017 is finished. ### 1.1 Spoken numerals (C3a)
Building blocks of the C3a spoken form, added 2026-10-01 (spike follow-up F3, D92–D100), all `needs native review`. The Mongolian column holds the **attributive** form used before a unit noun, and the Definition gives the plain form for reference. A compound number puts the larger part first, each part in its attributive form, separated by a space: 25 → «хорин таван», 150 → «зуун тавин», 990 → «есөн зуун ерэн». Every entry of the companion table [`glossary-c3-spoken.tsv`](glossary-c3-spoken.tsv) is built only from these rows plus the C3 units «метрт», «километрт», «километр» and «метрээс бага». These words are spoken only. They are never shown on screen, where digits stay (C3), and they do not stand alone in voice or UI. The PO pre-reviews them (D98), and the NAV-007 panel decides (AC 8).
