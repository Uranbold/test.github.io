## 1. Scope

In scope: all 73 acceptance criteria, at the level this environment allows; the GPX set G1–G9 plus QA variants **G3b**
(the 30 s GPS gap covers a turn), from round 1 **G3c, G3d, G5b, G6b, G6c** (§4: the D1 step catch-up and its
outlier gate), from round 2 **G6d** (§4: the D9 held position near a turn) and from round 3 **G6e, G6f, G10** (§4: arrival
gating, ADR-0009 Amendment 1 / Amendment 3 §5); the story edge cases that can be simulated (GPS loss/tunnel, outlier, poor accuracy,
network loss on the route and while off-route, 429 with every `Retry-After` form, 5xx, 12 s timeout, `NoRoute` /
`NoSegment` / 171 / other 400 / 413 / unparsable 200, back on the old route before the reroute answer, «Дуусгах»
during an episode, arrival then driving on, mute, language switch mid-route, English UI, walking); the browse screens
S1–S4 in Compose (portrait and landscape, day and night, font scale 100 % and 200 %); the API contract of the Android
guidance profile and the backend checks BE-1 / BE-2 (the backend lane produced no result in this delivery).

Out of scope (story): iOS (NAV-015), lanes (NAV-013), speed limits (NAV-014), background/lock-screen polish (NAV-012),
search assistance, alternatives and reverse geocoding (NAV-011), Android Auto/CarPlay, store release (D17).
NAV-002/003/004 web behaviour is not changed; the web unit tests are run unchanged (AC 29).

**Not testable here, listed for the reference device (AC 73, §6):** MapLibre rendering, real TTS and the Mongolian
voice, audio ducking and chime audibility, real GPS and tunnels, foreground service with the screen off ≥ 10 min, Doze
and OEM savers, the OS permission and notification dialogs, battery and CPU over a 30 min drive. These need the PO's
phone and a gateway the phone can reach (**NAV-008 staging; a dependency, not a blocker for JVM verification**).

## 3. How to run

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8080/health          # must be 200; otherwise wait and retry
cd mobile/android && export ANDROID_HOME=/opt/android-sdk
./gradlew assembleDebug lint :app:testDebugUnitTest --rerun --continue \
  -Pnav.hostFerrostar=required -Pnav.liveGateway=http://127.0.0.1:8080          # all JVM, Robolectric, replay and live tests
./gradlew :app:testDebugUnitTest --tests 'mn.navmn.app.qa.*' -Pnav.hostFerrostar=required   # QA tests only (offline)
cd ../.. && tests/.venv/bin/python tests/api/nav005/contract_nav005.py --base-url http://127.0.0.1:8080
python3 tests/android/nav005/static_checks.py
python3 tests/gpx/nav005/make_gpx.py --check
(cd web && npx vitest run)                                                         # AC 29: web tests unchanged
```

Pacing: `QaLiveGatewayTest` keeps ≥ 1 s between live route requests; `contract_nav005.py` ≥ 0.55 s.
