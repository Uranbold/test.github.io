## 1. Scope

In scope: all 46 acceptance criteria, the golden query set (tiers A, B, C), the story edge cases that apply to a
search client (Cyrillic vs Latin, Russian-layout vowels, typos, abbreviations, repeated khoroo names, no results,
gateway down, offline, 429 with and without a readable `Retry-After`, 400, slow network, language switch while a list or
card is open, traditional Mongolian script, very long input, out-of-order responses, out-of-coverage reverse points,
decimal-comma and swapped coordinates, GPS stale / not activated for the bias).

Carried NAV-002 follow-ups (trace to NAV-002, not to NAV-003 AC): 1 (AC 37 loading pill) is checked with the
**unchanged** NAV-002 screencast test; 2 and 3 are static checks of the design docs and the client (see §3 "Carried").

Out of scope (story): routing, "Get directions", voice guidance and rerouting (so **no GPX fixtures** are added: NAV-003
has no route), recent searches, native apps, Safari/iOS, Firefox/Edge (automated runs are Chromium only, D14), battery/CPU
drive. **No API tests** are added: NAV-003 changes no contract, and `search` / `reverse` are covered by the NAV-001 suite
(`tests/api/nav001`). NAV-001 and NAV-008 tests are not changed.

### Simulation (browser only, story "Test approach")
- `page.route('**/v1/search?**')` / `('**/v1/reverse?**')`: fixture features, empty results, 400, 429 (with
  `Access-Control-Expose-Headers: Retry-After` and `Retry-After: 3`, and without the header → 5 s), 502/503/504,
  network abort, **no answer** (8 s client timeout), delays (loading, out-of-order responses).
- **CORS failure:** a fulfilled response *without* `Access-Control-Allow-Origin` is let through by Playwright
  interception (checked 2026-09-30), so the test sends a **mismatched** origin, which Chromium enforces.
- Offline: `context.setOffline()`. Location: Playwright geolocation permission + position. Reduced motion:
  `emulateMedia({ reducedMotion: 'reduce' })`. Touch: CDP `Input.dispatchTouchEvent` with `hasTouch`.
- **Live gateway** only for AC 10, 12, 14–16 (golden set), 28, 29, 32. Rate: rows and samples are paced so the run
  stays **≤ 2 search/reverse requests per second** (about 70 live requests for the golden set, 20 for AC 12).
