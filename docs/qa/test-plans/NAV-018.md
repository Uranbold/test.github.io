## 1. Scope

In scope: all 38 AC at the level the JVM/Robolectric environment allows; the ADR-0015 risk checks the architect asked
for (late-fix guard, shared search 429 cooldown, row i = step i's own manoeuvre); the existing Android suite as
regression; the NAV-005 static/resource checks; `npx vitest run` in `web/` (AC 35: shared fixture unchanged).

Out of scope (story): guidance from a chosen start, waypoints, saved places, a turn list during guidance, the typed-coordinate
rule itself (D137/D140), iOS (NAV-015), web behaviour, `openapi.yaml`/gateway changes, a toll option.

**Not testable here:** everything in AC 38 (real Android phone; the PO has none yet); anything that needs MapLibre's native
library (drawn start ring and step point, `NavMapController.focus` camera ease, camera fit with both markers on a real map);
real TalkBack announcements (only the semantics tree is checked).
