## 1. Rules for the run

- **Isolation.** Every command targets `NAV_ENV_FILE=/var/tmp/nav006-test/nav006.env` (project `navmn-nav006`). No `make up/down/restart/rebuild-data` and no request burst against `:8080`. The shared stack's container IDs, `StartedAt` and `RestartCount`, and a listing hash of `backend/data` (path, size, mtime, inode; the live Photon directory is hashed separately, information only) are recorded before and after. `/health` on `:8080` is probed every 2 s for the whole run.
- **No retries in the loop.** Half of the loop clients keep one connection alive, half open a new connection per request. A request that fails on a stale keep-alive connection counts as a failure. A failure is a connection error, no response within 5 s, or a status other than 200 (206 for `Range`) (AC 15).
- **Test data.** Slot A is built from the copied cached extract (geo2day mirror, `Last-Modified` 2026-09-29). Slot B is built from a **changed** extract: `OSM_SOURCES` lists the geo2day mirror first (`Last-Modified` 2026-10-03) and the cached copy as fallback (AC 2, AC 36), so the switch replaces real data with newer data and AC 12 compares two different graphs. If the mirror is blocked, the fallback gives `skipped: unchanged`; the item is then rerun with `FORCE=1` and this is recorded.
- **Relaxations** (AC 37, ADR-0014 §7), set only in the test config and logged by every run: `REBUILD_MAX_DATA_AGE_HOURS=0` (3(f) off), `REBUILD_MIN_FREE_GB=4`, `REBUILD_HARD_FLOOR_FREE_GB=1`. `REBUILD_REQUIRE_NOT_OLDER=1` stays on. Fault injection `REBUILD_TEST_FAULT=verify` with `REBUILD_ALLOW_TEST_FAULTS=1`, test project only.
- **Disk.** The container had about 8.6 GB free. Evidence goes to `/var/tmp/nav006-qa-evidence` (outside git and outside the test root, about 3 MB, kept as run logs). Hard-linked aux files are never opened for writing.
