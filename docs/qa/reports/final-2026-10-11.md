**QA-FINAL-01: NAV-001 AC 3 / AC 8 fail after SEC-4A (requirements conflict).**
- Steps: `python3 tests/api/nav001/static_checks.py` at `661265c`.
- Expected (NAV-001 AC 3, AC 8, Context, R1; D127 allows the mirror in dev/test): `backend/.env.example` has
  `OSM_PBF_URL=https://geo2day.com/asia/mongolia.pbf` with a dev-only mirror comment and a **commented** Geofabrik
  production value; the README dev-coverage section names the dev-only mirror default.
- Actual: `OSM_PBF_URL=https://download.geofabrik.de/asia/mongolia-latest.osm.pbf` is the default (SEC-4A BE-7:
  "a third-party mirror is no longer a default"), the commented Geofabrik line is gone, and the README calls geo2day
  the "former dev default, removed in SEC-4A". Failing checks: AC03.osm_url_default_mongolia_mirror,
  AC03.osm_url_dev_only_mirror_comment, AC03.geofabrik_commented, AC08.dev_coverage_documented.
- Impact: none for staging/production (already Geofabrik, D127). In the agent dev container, where Geofabrik is
  blocked, a fresh `make up` needs `OSM_PBF_FILE` set by hand, which conflicts with AC 1 "no manual steps" (not
  executed here: it needs a full data build).
- Classification: not a code bug. The change is security-motivated, but it changes a story AC without a story
  amendment (SEC-4A has no story). QA keeps the checks as they are until the story changes; if the PO accepts the
  new default, the BA amends NAV-001 AC 3/8 and QA replaces the four checks (change-request rule: the old tests are
  updated, not deleted).

**QA-FINAL-02: NAV-017 `layout.test.mjs` AC38 arrival (night) timed out under load.**
- Steps: run `./nav017/run.sh` (3 workers) while a Gradle build runs on the same 4 vCPUs (load ≈ 11).
- Expected: pass. Actual: `Test timeout of 300000ms exceeded` inside `axeAnalyze` (`page.clock.runFor` loop). The
  same test passes alone at load < 1 (2/2, 1.8 min each). No product change is involved; the fix is in QA's harness
  (fewer workers for `layout.test.mjs`, or a longer timeout for the axe scans). Not fixed in this light pass.
